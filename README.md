# Berk — Livro dos Dragões

Projeto acadêmico de front-end de Gustavo Mesquita. Site sobre meu hobby: início, catálogo de 12 dragões, quiz e apresentação pessoal.

## Organização
- `index.html`: entrada do site
- `html/`: páginas adicionais
- `css/style.css`: estilos e responsividade
- `js/dados.js`: informações dos dragões
- `js/app.js`: busca, filtros, modal e favoritos
- `js/quiz.js`: perguntas, pontuação e reinício do quiz
- `imagens/`: recursos locais

## Executar
Abra index.html no navegador. Não há compilação ou backend.

## GitHub Pages
Envie o conteúdo desta pasta para a raiz de um repositório. Em Settings > Pages, selecione Deploy from a branch, branch main e pasta /(root). A publicação privada de revisão no ChatGPT não substitui o GitHub Pages exigido para a entrega.

## Funções
Busca sem diferenciar acentos, filtro por classe, favoritos em localStorage e detalhes em dialog nativo (fecha com Escape).
